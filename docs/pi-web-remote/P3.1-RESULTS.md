# P3.1：原 App 界面对齐与离线模拟器验证

## 1. 结论与边界

已在隔离 Android 模拟器构建、安装并实际点击独立测试 APK；聊天主体改为复用原 App 的展示组件，完成本次离线原生业务场景验证。

**这是“原生 UI＋真实 PiWebRemoteClient＋内存假 RPC”的设备验证，不是作者服务、真实 Host／Noise 通道、SDK／模型、手机真机或生产验收。** 未启动第二个 Pi／ACP／SDK AgentSession，没有登录、注册、真实会话写入、WebView 页面或部署。原有 ACP Pi 保留。

本记录补充 [P3 执行记录](P3-RESULTS.md)，不将下述模拟器结果勾成 [真实端到端验收](ACCEPTANCE.md)。未与用户已安装 App 的个人设置／截图逐像素比对，不读取其数据；用户对视觉效果的最终确认不由源码复用或自动测试代替。

## 2. 用户决定

- 优先模拟器；模拟器确实不可用才转真机＋ADB。软件模拟器已经可用，本轮未连接手机。
- 允许在工作树外按官方许可证隔离安装 Android 工具链，不 sudo、不修改 KVM 权限。
- 独立包名 `dev.piweb.remote.fixture`、显示名“Pi Web Remote 测试”、scheme `piwebremote-fixture`，使用全新隔离测试签名，不覆盖原 App。
- 用户指出初版与已安装界面不同，明确选择先对齐原 App UI，再继续验证。初版简化页与黄色控制条不是最终界面验收证据。
- 仍不授权子代理／独立审查、真实账号／Host／模型、生产操作或 WebView 实现。

## 3. 源码事实

### 复用界面，而不是伪装 ACP

- `apps/android/src/screens/pi-web-screen.tsx` 保留独立 Pi Web 控制器，复用 `TopBar`、`BlurHeaderFrame`、`KeyboardInset`、`ChatComposer`、`MessageBubble`、`ToolRow`、`WelcomeMessage` 和原问卷样式。
- 会话抽屉复用 `host-sessions-drawer.tsx` 导出的原样式及交互布局，不直接调用原抽屉中的 ACP 会话／工作区操作。
- 共用输入组件的菜单、快捷提示与状态文案可按实际能力提供；旧调用默认行为不变。Pi Web 不显示模型选择、附件、创建会话等未接线入口，也不显示“可直接插话”来暗示支持 steer／排队。
- 问卷继续按原 questionIndex／optionIndex 关联，保留自由输入、preview 安全文本、题目／整份备注、整份提交、取消、unknown 查询与跨端失效。不复用旧问卷按 label 关联及强制全题非空的语义。
- `services/pi-web.ts` 的消息适配仅供原组件展示，不写 ACP store，不制造序号、时间、模型、usage、frameRpcId 或 ACP 延迟详情。历史 ID 仍是原 entry ID；`local-live` 仅是尚未持久化的组件局部标识，不是协议 messageId。
- 读取较早历史与发送回执均有视图换代保护；切会话后不将旧结果或草稿清空动作投到新视图。

### 独立离线入口

- `fixture-entry.tsx` 不被正常 App 的 `package.json/main` 引用。测试控制移入单独面板，正常页面只保留明确的离线测试标记；测试语言固定简中，不读取或修改原 App 语言偏好。
- `src/fixtures/pi-web-rpc.ts` 复用真实协议校验及客户端状态机，只有内存中的目录、历史、流和操作记录；没有 socket、账号、真实 Host 或模型执行器。
- `scripts/prepare-pi-web-fixture.mjs` 只复制源码到固定工作树外目录，在副本替换入口、身份、scheme 并禁用备份与 INTERNET 等权限，不改原 app.json、main、锁文件或签名。
- `scripts/finalize-pi-web-fixture.mjs` 只在副本确认测试配置并接入新的隔离签名；不复制原 App 或生产签名材料。
- 原有依赖包含可选 WebView 模块；本链路不挂载相关页面，不等于承诺 APK 的依赖闭包完全没有 WebView 代码。

- 冷会话只读、返回活动会话；未创建或恢复 Agent。
- 相同文本的两个历史条目保留不同真实 entry ID；原消息、思考折叠、普通工具行正常展示。

- 三题整份问卷：单选索引 1，多选索引 0＋1 并填写补充文字，第三题只填自由文字；填写题目及整份备注，提交一次并看到“答案已采纳”。夹具回读摘要为 `题1=[1] 题2=[0,1]+文字 题3=[]+文字`，不是按 label 猜测。
