# Pi Web Remote 开发入口

目标：让 Android 原生聊天、完整问卷和内嵌 Pi Web 网页通过 DSH Remote 的 E2E 网络，接入当前同一个 Pi Web/SDK 实例；不占 VPN 槽位，不另起执行器。
