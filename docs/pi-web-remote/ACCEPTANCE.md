## 1. 验证分层与权限

- L0 仓库/文档静态自检：SHA、变更范围、链接与忽略规则。本轮允许，不执行业务代码。
- L1 无模型核心契约：固定事件/隔离假 HTTP 上游、协议/状态机。需开发和项目测试授权；不是配置一个模拟 provider，也不接生产。
- L2 本地真实集成：隔离 Pi Web/插件、native 代理、模拟器或真机。需明确原型/工具链/设备授权；不能擅自启动第二份生产执行器。
- L3 真实业务与跨网：已批准的新 App/Host 身份、作者服务、现有原会话、蜂窝/P2P/TURN/Relay。账号/设备和业务写入分别批准。
- L4 独立审查/生产：获准 review 后执行新的安全与可实施性审查，再批准工件安装/包装器变更/重启。旧 review 不能覆盖本设计新增能力。

不自动跑全仓脚本：上游 Android check/test 会生成 renderer，build 不一定等于 APK；先审查副作用与依赖。核心包测试失败保留原错误，不靠 skip、改模型或删除上限变绿。

## 2. 功能验收清单

### A. 原实例与会话连续性

- [ ] App/普通网页/无痕网页关联同一原 session 与 wrapper/SDK；附着前后创建计数不增加，事件连续且一次实际工具执行。
- [ ] 原实例已停止/被替换、附着与停止竞争时明确失败，不调用自动创建/恢复分支。
- [ ] 历史与 live 无丢失/重叠污染；相同短文本不被误去重，真实 message/tool IDs 保持。
- [ ] 网页发起任务时 App 能观察；运行/排队/Stop 来自上游真实状态，不能伪装空闲。
- [ ] App/Host 断线、后台恢复、重新订阅不重发 prompt；unknown 操作先核对。
- [ ] 退出 App、关闭 WebView、停止新 Host 只清理自己的资源，不取消原 Agent 或释放他人租约。

### B. 完整原生问卷

- [ ] 单选、多选、自定义、多题整份提交和明确取消；合法空答案、preview/notes 的范围单列。
- [ ] 正确回到原 toolCall，不发新 prompt；错误答案不消费未决问卷。
- [ ] 网页先/App 先/同时提交、网页部分作答后 App 提交、取消与答案竞争，只有一个最终工具结果。
- [ ] 重复同 operation、异 payload 同 ID、迟到/关闭后/旧 instance 请求有明确回执；HTTP 200 不等于 accepted。
- [ ] 请求或回执丢失、Host 重启、App 重启、权威重启/缓存过期不会自动重放。
- [ ] 外部完成会关闭本问卷正在等待的 RPC UI，不关别的问卷；Stop/超时不制造“答案已采纳”。
- [ ] 断线重连快照恢复真实 pending 集合；closed 和快照窗口竞争不留下幽灵问卷。

### C. App 内网页与 HTTP 传输

- [ ] 原生/网页切换到同一 session；网页退出不终止原任务。
- [ ] 页面、相对/绝对资源、API POST body、Cookie、Host/Origin、CSP、重定向正常。
- [ ] 安静超过 30 秒、多次心跳与多次空读的 SSE 不被当 EOF；取消、截断和真正 EOF 正确区分。
- [ ] 64 KiB 分块、1 MiB 请求体、64 MiB 累计响应、16 handle、256 KiB WS 消息及有界积压的边界可解释，超限释放资源。
- [ ] 长 SSE 达限额后只做重连/快照，不触发新任务；资源并发和背压不拖死聊天流。
- [ ] 上传/下载有支持范围和超限提示；必要 WS 有实测，否则“不适用”有明确依据。
- [ ] 后台暂停、网络切换、连接替换时旧句柄不能访问新连接数据。

### D. 端点与账号安全

- [ ] 手机仅回环监听，有不可预测本地认证及来源隔离；随机端口不是唯一屏障。
- [ ] 拒绝恶意本地 App、跨端口 Cookie、外部 origin/iframe/导航/子资源、DNS/Host 绕过及外部重定向。
- [ ] WebView 脚本读不到 Remote token/私钥，无通用 native bridge；Service Worker/缓存按已审策略受控。
- [ ] Host 只允许 `127.0.0.1:30141`，任意目标/CONNECT、跨 peer handle、匿名/非授权/撤销设备请求失败关闭。
- [ ] Server membership 与固定 peer key 校验保留；公钥变更、撤销、过期凭据不被当瞬态错误无限重试。
- [ ] 原生 Pi Web backend 不启动 pi-acp/Codex、不读原 DSH 身份、不调用未授权模型/配置 API。
- [ ] 日志无 token、私钥、Authorization、Cookie、原始对话/工具输出；错误日志也经过脱敏。
- [ ] 网页的高权限明确告知：原生 allowlist 不能限制网页本身已经提供的功能，不能误称 OS 沙箱。

### E. APK、托管服务与实际网络

- [ ] APK 源码/锁文件/签名/哈希可追溯；独立 applicationId/scheme/组件，不覆盖原版、不搬身份，不占 VPN。
- [ ] 作者服务已明确允许该独立 Host，账号授权、注册、撤销及限额/费用有记录；官网可打开不算准入通过。
- [ ] 在可直连环境取得业务真实走 P2P 的证据，不只看开关；限制条件与 ICE 结果脱敏记录。
- [ ] TURN 与 Relay 兜底仍经过 Noise，未出现业务明文路径；单看抓包看不到明文不是完整 crypto 审查。
- [ ] 手机关闭 Wi-Fi 后完成真实蜂窝验证；同 Wi-Fi 结果不替代跨网。
- [ ] 电脑唤醒、WSL 在线的前提清楚；未另批时不扩成冷启动/防睡眠验收。

## 3. 证据格式

每次实际检查记：日期、源码与构建哈希、环境/设备版本、授权范围、场景、预期、实际、通过/失败/未验证、脱敏证据位置。失败记录原始错误类型和原因是否已确认，不能把推断写成事实。

本地大日志、截图、录屏、APK 放忽略的 `artifacts/`，提交文档只存必要摘要与哈希。不保存授权码、token、私钥、会话正文或敏感抓包。工具不可用时列明未检查项，不当通过。

对“同实例”的证据至少组合：原 registry/wrapper 的关联、订阅期间的创建/生命周期记录、连续消息/工具事件和单次实际执行。相同 session ID、历史或 PID 均不足以单独证明。

## 4. 回滚顺序与禁止项

1. 停止接收本项目新写操作，核对所有 unknown 提交。已经生效的任务/答案不能靠卸载撤销，禁止自动补发或自动拒答。
2. 关闭本 App 的 WebView/本地代理和新 Host 连接，释放自己的订阅/handle；不调用原 Agent abort、全局 logout/reset 或共享服务 stop。
3. 仅按授权撤销新 App/Host 的设备身份。原 DSH、原 App 和原 Pi Web 运行/身份保持。
4. 若尚未改生产包，原桌面网页应可继续操作现有问卷；验证这个事实，不宣称“停止桥接就必然安全”。
5. 若已获批部署 Pi Web/问答插件补充，先等活跃工具/问卷完成，或取得明确中断授权，再回退固定源码工件及依赖引用；不在悬挂 RPC 问卷中热删实现。
6. 不恢复旧 runtime/session 备份覆盖当前数据，不编辑 session JSONL。新密钥/凭据清理需独立范围确认，避免误删 DSH/Pi Web。
7. 包装器/认证回退先确保远端入口关闭；不能留下远端仍在线但认证已撤销的状态。服务重启仍需明确授权和任务窗口。
